# 🛒 ShopEase — E-Commerce Store

A full-stack e-commerce web application built with Node.js, Express, MongoDB and HTML/CSS/JS.

## 🔗 Live Demo
👉 https://lucent-pithivier-ed9d04.netlify.app

## ✅ Features
- Product listing with search and filter
- User registration and login
- Shopping cart
- Order placement
- Order history

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Deployed:** Netlify (frontend) + Render (backend)

## 🚀 How to Run Locally
1. Clone the repo
2. cd backend
3. npm install
4. npm run dev
5. Open http://localhost:5000
